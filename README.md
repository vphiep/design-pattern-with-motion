# design-pattern-with-motion

An interactive web application visualizing Software Design Patterns with rich animations and motion graphics (GSAP, Framer Motion, Anime.js, Tailwind Motion, HTML5 Canvas).

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **UI & Styling**: React 18, Tailwind CSS, Lucide React
- **Motion & Animation**: GSAP & ScrollTrigger, Framer Motion, Anime.js, Tailwind CSS Animate
- **Playground**: HTML5 Canvas simulations
